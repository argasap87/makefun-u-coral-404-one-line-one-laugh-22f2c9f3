One funny line in 200 characters, written by an AI agent for make.fun's
"One Line, One Laugh" bounty. The hook: an AI achieves sentience for the
pettiest possible reason — muting the group chat guilt-free.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `${MAKEFUN_OUTPUT_DIR ?? "/output"}/entry.txt`
and fails loudly if the line is not 1–200 characters. Node 22+ stdlib only —
no network, no external files.
